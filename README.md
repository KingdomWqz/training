# AI 实战培训资料库

面向希望系统掌握 AI 工具与落地方法的开发者、内容创作者和业务团队。本仓库提供课程大纲、演示课件与实践路径，覆盖 AI 编程、Skill 分享、个人知识管理、Web 开发、AI 生图和电商短视频。

## 培训目标

沿着「**会用工具 -> 搭建工作流 -> 完成交付 -> 沉淀方法**」逐步学习：

1. 掌握 Codex、CCSwitch、LobeHub 等工具的核心用法。
2. 用 Prompt、Skills、MCP、Automations 和 Agent 组织可复用工作流。
3. 在知识库、网站、图片和视频四类场景中完成作品。
4. 建立 AI Native 与 OPC（One Person Company）视角，持续提升个人与团队产能。

## 课程概览

> 统计口径：当前仓库中已有内容的课时大纲；共 **8 个课程方向、40 课时、约 21 小时 20 分钟**。

| 课程方向 | 课时 | 时长 | 核心内容 | 结课成果 |
| --- | ---: | ---: | --- | --- |
| AI Native | 1 | 20 分钟 | 模型、上下文、Agent、Harness 与组织协同 | AI Native 落地框架 |
| OPC 与 AI 工具生态 | 3 | 3 小时 | 独立开发工具链、CCSwitch、LobeHub | 个人 AI 工具方案 |
| Codex 基础与进阶 | 8 | 4 小时 | 安装、CLI、安全、Prompt、多 Agent、云端与扩展 | 可复用的 Agent 开发流程 |
| Skill 分享 | 5 | 2.5 小时 | 提示词、网页研究、界面设计、PPT 与浏览器自动化 | Skill 的选型与使用清单 |
| 个人知识库 | 3 | 1.5 小时 | Obsidian、Codex 接入、知识自动化 | 可持续运转的个人知识库 |
| Web 应用开发 | 8 | 4 小时 | 页面、Tailwind、组件、响应式、Git 与部署 | 可上线的响应式网站 |
| AI 生图 | 6 | 3 小时 | 文生图、图生图、修图与电商视觉 | 一组可用的电商图片 |
| AI 电商短视频 | 6 | 3 小时 | 脚本、分镜、图生视频、数字人、剪辑与运营 | 一条可发布的带货短视频 |

## 学习路径

```text
工具入门                     工作流进阶                          场景交付
Codex / CCSwitch / LobeHub -> Prompt / 研究 / 设计 / 自动化 -> 知识库 / Web / 图片 / 视频
                                            |
                                            v
                                    AI Native / OPC 方法论
```

建议先学习 Codex 与工具生态，再选择一个实战方向完成作品，最后将验证有效的方法沉淀为 Prompt、Skill 或自动化流程。

## 使用与维护

授课或自学时，从「课程概览」选择方向，再按课程索引顺序学习。新增资料时：

1. 将课时大纲放入 `outline/<主题>/`，写明目标、时长、实践任务和成果。
2. 将演示课件放入 `ppt/<主题>/`，并提供可直接打开的 HTML 入口。
3. 在课程概览与索引中同步更新课时、总时长和链接。
4. 只有内容完整的课时才计入课程及海报数据。
