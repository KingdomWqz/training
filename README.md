# AI 实战训练营

**面向职业院校在校学生，从基础认知到综合实战，逐步建立完整的 AI 应用能力。**

课程覆盖 AI 编程、个人知识管理、Web 开发、AI 生图和电商短视频，通过讲解、演示与动手练习，帮助学生理解 AI 工具在不同专业场景中的应用。

> 不只是听概念、记术语。课程从工具入门逐步进入场景实战，在动手过程中理解方法、熟悉工具。

## 四类场景实战

课程将 AI 工具与职业场景结合，覆盖以下四类实践内容：

| 实战场景 | 主要内容 | 应用方向 |
| --- | --- | --- |
| Web 应用开发 | 页面制作、样式设计、组件、响应式适配与部署 | 网站开发与项目实践 |
| AI 电商视觉 | 文生图、图生图、修图与商品场景设计 | 网店装修、电商运营与视觉设计 |
| AI 电商短视频 | 脚本、分镜、图生视频、数字人与剪辑 | 短视频运营与直播电商 |
| 个人 AI 知识库 | 资料整理、内容检索与知识自动化 | 课程学习、证书备考与资料管理 |

学习过程中还会接触 AI 编程、提示词、智能体和自动化，让 AI 从“聊天工具”变成你的学习与创作搭档。

## 不同专业都能学以致用

课程内容前后衔接、共同组成完整体系。不同专业的学生可以把所学能力应用到各自的学习和职业场景中。

| 专业或兴趣 | 重点应用场景 | 能力价值 |
| --- | --- | --- |
| 计算机、软件、网络技术 | AI 编程、Web 应用与自动化 | 提升项目开发与问题解决能力 |
| 电商、市场营销、跨境电商 | 商品视觉、营销内容与电商短视频 | 提升商品运营与内容生产能力 |
| 数字媒体、艺术设计、动漫 | AI 生图、界面设计与视频制作 | 丰富视觉表达与内容创作方式 |
| 商贸、文秘、旅游及其他专业 | 知识管理、资料研究与 AI 辅助表达 | 提升学习、办公与内容整理效率 |

课程从基础开始讲解，不要求提前掌握所有 AI 工具或具备编程基础。学习 Web 与 Codex 内容时，会逐步接触文件、终端和 Git 等基本操作。

## 学习方式

```text
基础认知 -> 工具能力 -> 知识库 / Web / 图片 / 视频实战 -> 进阶方法
```

1. **认识场景**：了解 AI 在学习、开发、设计和内容制作中的典型用法。
2. **边做边学**：在具体任务中理解提示词、AI 工具和工作流。
3. **综合应用**：连接多个工具与步骤，解决更完整的场景问题。
4. **回顾方法**：总结有效做法，逐步建立可复用的 AI 使用习惯。

## 开始前需要什么

- 一台可以联网的电脑；具体系统与软件版本以授课说明为准。
- 一个常用邮箱，用于注册课程涉及的 AI 工具或 GitHub 账号。
- 不要求提前掌握所有工具，也不要求每位学生都有编程基础。
- 部分第三方 AI 服务可能存在免费额度、地区或账号限制，授课前应由讲师统一确认并准备替代方案。

## 给讲师与维护者

### 仓库结构

```text
training/
├── outline/   # Markdown 课程大纲
└── ppt/       # HTML 演示课件与版式资料
```

### 使用与维护

授课或自学时，按照课程体系和课程索引顺序学习。新增资料时：

1. 将课时大纲放入 `outline/<主题>/`，写明目标、时长、实践任务和成果。
2. 将演示课件放入 `ppt/<主题>/`，并提供可直接打开的 HTML 入口。
3. 在课程概览与索引中同步更新课时、总时长和链接。
4. 只有内容完整的课时才计入课程及海报数据。
