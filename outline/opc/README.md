# OPC：个人开发者与 AI 工具生态专题

本专题面向希望以一人团队（One-Person Company，OPC）方式完成产品构思、开发、发布与迭代的学习者。课程把工具链、配置管理和智能体平台放在同一条工作流中讲解：先建立全景认知，再用 CCSwitch 统一配置，最后用 LobeHub 把 AI 能力组织成可复用的智能体。

## 专题目标

完成本专题后，学员能够：

1. 按产品流程搭建轻量、可持续的个人开发工具链。
2. 使用 CCSwitch 管理模型供应商、MCP、Skills 与 Prompts，降低多工具切换成本。
3. 使用 LobeHub 创建智能体，接入技能与知识库，并组织多智能体协作。
4. 根据任务复杂度和预算，为自己的 OPC 工作流选择合适的工具组合。

## 学习路径

| 顺序 | 大纲 | 时长 | 重点 |
|------|------|------|------|
| 1 | [独立开发者工具全景](./01-IndieDevTools.md) | 60 分钟 | 从知识管理、AI 辅助、开发环境到部署运维的完整工具链 |
| 2 | [CCSwitch：AI 编程工具配置管理](./02-CCSwitch.md) | 60 分钟 | 统一管理供应商、MCP 服务器、Skills 与 Prompts |
| 3 | [LobeHub：AI 智能体平台快速入门](./03-LobeHub.md) | 60 分钟 | 创建智能体、接入知识库与技能、开展群组协作 |

## 贯穿工作流

```text
想法与知识整理
      ↓
工具链选型（01）
      ↓
配置统一与能力复用（02）
      ↓
智能体创建与协作（03）
      ↓
开发、发布、运营与持续迭代
```

## 课前准备

- 准备可访问相关服务的网络环境，并注册需要使用的账号。
- 安装终端、编辑器和 Git；工具全景课中的演示工具可按个人设备择一准备。
- CCSwitch 课准备至少两个模型供应商的 API Key。
- LobeHub 课准备一份可上传的示例文档，用于知识库和智能体演示。

> 工具版本、模型名称、免费额度和平台政策变化较快，授课前请以各项目官方文档为准。
