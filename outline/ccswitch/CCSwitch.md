# CCSwitch 教学大纲：AI 编程工具配置管理

## 课程概述

**课程名称**：CCSwitch — AI 编程时代的工具配置管理实践

**适用对象**：在校学生（计算机相关专业，或对 AI 编程感兴趣的跨专业学生）

**课程时长**：60 分钟

**先修知识**：基础编程能力、命令行使用经验

---

## 课程目标

1. 理解 AI 编程工具生态现状及配置管理痛点
2. 掌握 CCSwitch 的核心功能与使用方法
3. 激发产品思维与用户需求洞察

---

## 第一部分：AI 编程工具生态与 CCSwitch 介绍（15 分钟）

### 1.1 AI 编程工具的爆发（5 分钟）

- 当前主流 AI 编程工具：
  - **Claude Code**：Anthropic 出品的命令行 AI 编程助手
  - **Codex**：OpenAI 的代码生成工具
  - **OpenCode / OpenClaw / Hermes**：其他新兴 AI Agent 工具
- 配置格式差异：JSON、TOML 等各不相同

### 1.2 痛点分析（5 分钟）

- **配置碎片化**：多工具、多格式、多位置
- **切换成本高**：手动编辑配置文件容易出错
- **缺乏统一管理**：MCP 服务器、Skills、Prompts 各自为政
- **多设备同步难**：不同设备需要重复配置

### 1.3 CCSwitch 的诞生（5 分钟）

- 项目背景：36 岁外贸从业者 Jason 的转行故事
- 项目数据：GitHub 20,000+ Stars，130 万次下载
- 核心理念：**把"配置"和"代码"彻底解耦**
- MIT 开源协议，完全免费

---

## 第二部分：核心功能详解（25 分钟）

### 2.1 供应商管理（10 分钟）

- **50+ 预设供应商**：Anthropic、OpenAI、Google、国内中转服务
- **一键切换**：支持 Claude Code 热切换（无需重启终端）
- **系统托盘快速切换**：无需打开完整应用
- **实时演示**：添加供应商 → 切换供应商 → 验证生效

### 2.2 MCP 服务器管理（8 分钟）

- 什么是 MCP（Model Context Protocol）
- 统一管理面板：跨 Claude、Codex 等工具
- 双向同步机制
- Deep Link 导入功能
- **演示**：添加一个 MCP 服务器并同步到多个工具

### 2.3 Skills 与 Prompts 管理（7 分钟）

- Skills 安装：从 GitHub 仓库或 ZIP 文件一键安装
- Prompts 编辑：Markdown 编辑器 + 跨应用同步
- 支持文件：CLAUDE.md / AGENTS.md
- **演示**：安装一个 Skill 并应用到 Claude Code

## 第三部分：动手实践（15 分钟）

### 3.1 环境准备（3 分钟）

- 下载地址：https://ccswitch.io
- 支持平台：Windows、macOS、Linux
- 安装步骤演示

### 3.2 基础配置（10 分钟）

1. **添加第一个供应商**
   - 选择预设模板
   - 填入 API Key
   - 启用供应商

2. **切换供应商**
   - 主界面切换
   - 系统托盘切换
   - 验证切换效果

3. **管理 MCP 服务器**
   - 添加 MCP 服务器
   - 跨工具同步配置

### 3.3 高级功能简介（2 分钟）

- **云同步**：Dropbox / OneDrive / iCloud / WebDAV
- **本地代理**：自动故障转移与负载均衡
- **用量追踪**：Token 使用统计

## 第四部分：产品思维与职业启示（5 分钟）

### 4.1 需求洞察（2 分钟）

- 如何发现真实痛点
- 从"能用"到"好用"的设计思维
- 克制设计：不破坏基本体验

### 4.2 Jason 的故事（2 分钟）

- 36 岁外贸从业者的转行之路
- 3 个月学完基础，6 个月做出 20,000 Stars 项目
- 核心能力：共情能力、产品思维、用户需求理解
- **AI 时代的技术门槛在降低，但对需求的理解变得更加重要**

### 4.3 职业发展建议（1 分钟）

- 开源项目经历对求职的价值
- 从工具使用者到工具创造者
- 保持学习的心态
