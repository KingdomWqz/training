# 第 8 课：发布上线与复盘
**目标**：发布网站，并总结可复用工作流。

**时间**：讲解 5 分钟｜跟做 20 分钟｜检查 5 分钟。

1. **讲解**：发布前移除测试文字、补标题描述、确认没有密钥。
2. **跟做**：按 Vercel 向导连接 GitHub 并部署；GitHub Pages 作为课后替代方案。
3. **检查**：用手机打开线上链接，记录一个改进点。

《我的网站工作流》手册、性能优化和端到端测试作为课后作业。
