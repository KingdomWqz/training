# 第 7 课：Git 保存与并行协作（进阶）
**目标**：学会保存版本；有余力时体验两个 Agent 分工。

**时间**：讲解 5 分钟｜跟做 20 分钟｜检查 5 分钟。

1. **讲解**：认识 `status`、`add`、`commit`、`log`，不提交密钥。
2. **跟做**：完成一次有意义的提交；有余力再建两个分支，分别改内容和组件并合并。
3. **检查**：`git log` 至少有 2 个提交且项目可构建。

冲突处理、Worktree 和 `/review` 放到课后挑战，避免课堂超时。
