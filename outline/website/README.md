# 综合实战：从零构建并发布个人网站

本项目拆为 8 个 30 分钟课时，面向零基础学员。每课固定：讲解 5 分钟、跟做 20 分钟、检查 5 分钟。请按顺序学习，课后练习不占课堂时间。

| 课时 | 文件 | 产出 |
|---|---|---|
| 1 | [01-idea-and-setup.md](01-idea-and-setup.md) | 需求卡、可运行项目 |
| 2 | [02-first-page.md](02-first-page.md) | 信息完整的首页 |
| 3 | [03-tailwind-style.md](03-tailwind-style.md) | 统一视觉样式 |
| 4 | [04-components.md](04-components.md) | 3 个复用组件 |
| 5 | [05-pages-and-content.md](05-pages-and-content.md) | 3 个页面与作品资料 |
| 6 | [06-responsive-testing.md](06-responsive-testing.md) | 手机适配与构建通过 |
| 7 | [07-git-collaboration.md](07-git-collaboration.md) | Git 提交与分支体验 |
| 8 | [08-deploy-and-review.md](08-deploy-and-review.md) | 线上链接与复盘 |

最终标准：三个页面、一个可复用组件、真实内容、手机端可用、线上可访问。
