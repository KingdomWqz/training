# 第 3 课：用 Tailwind 让页面变好看
**目标**：会控制颜色、间距、字体和布局。

**时间**：讲解 5 分钟｜跟做 20 分钟｜检查 5 分钟。

1. **讲解**：只认识文字、颜色、间距、圆角、`flex/grid` 五类 Tailwind 类。
2. **跟做**：让 Codex 解释并修改首页样式，确定一个主色、一个辅助色和统一圆角。
3. **检查**：顶栏、内容区、页脚齐全，颜色统一且没有横向滚动条。
