# 第 1 课：确定主题并准备工具
**目标**：写清网站要做什么，并启动 Next.js 项目。

**时间**：讲解 5 分钟｜跟做 20 分钟｜检查 5 分钟。

1. **讲解**：需求卡只写网站名称、目标访客、三项内容和喜欢的颜色；推荐个人名片/作品集，不做登录、支付、数据库。
2. **跟做**：认识项目、终端、浏览器、开发服务器；让 Codex 先列小步骤，再创建项目并运行 `npm run dev`。
3. **检查**：浏览器显示 Next.js 页面；说出项目文件夹和 `app/page.tsx` 的作用。

卡住时保存错误原文，先确认 Node.js 版本和当前目录。
