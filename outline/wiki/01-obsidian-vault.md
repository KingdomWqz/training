# 第 8 课：个人知识库方法论与 Obsidian 上手（30 分钟）

**教学目标**：
1. 理解「收藏 ≠ 拥有」：能说出个人知识库与网盘/收藏夹的本质区别，建立「捕获 → 整理 → 沉淀 → 检索 → 输出」的知识循环意识
2. 掌握 PARA 与卡片盒笔记法（Zettelkasten）两大主流方法论的适用场景，能结合自身工作选择组织框架
3. 独立完成 Obsidian 安装与 vault 初始化，掌握 Markdown、双链、标签、每日笔记四个核心操作
4. 理解「知识库本质是一个 Markdown 文件夹」这一关键事实，为下一课交给 Codex 管理建立认知铺垫

## 时间分配与内容大纲

### 一、导入：你的收藏夹正在吃灰（3分钟）
1. **现场调查**：微信收藏 / 浏览器书签 / 网盘资料，上一次打开是什么时候？收集学员痛点
2. **知识管理三大症状**：存了找不到（检索失败）、记了想不起（缺乏连接）、学了用不上（没有输出）
3. 引出本模块目标：搭建一个**能被 AI 维护**的第二大脑，闭环 = 捕获 → 整理 → 沉淀 → 检索 → 输出

### 二、两大方法论速览（7分钟）
1. **PARA**（Tiago Forte）：按「可行动性」组织

   | 层 | 含义 | 示例 |
   |----|------|------|
   | Projects 项目 | 有明确目标和截止时间 | 正在写的方案、本次课程练习 |
   | Areas 领域 | 长期负责、无终点 | 职业发展、健康、团队管理 |
   | Resources 资源 | 未来可能用到的主题 | 提示词工程资料、工具测评 |
   | Archives 归档 | 以上三类中不再活跃的 | 已结项项目 |

2. **卡片盒笔记法（Zettelkasten）**：按「连接」组织——原子化笔记（一篇只讲一个概念）、文献笔记与永久笔记分离、**链接优先于文件夹**
3. **MOC（Map of Content）**：手动维护的索引页，对抗文件夹层级的僵化；三者搭配：PARA 定骨架、卡片法做单元、MOC 做导航
4. **选型忠告**：不要一开始追求完美分类；结构是长出来的，不是设计出来的

### 三、Obsidian 核心速成（10分钟）
1. **为什么选 Obsidian**：
   - 数据是**本地纯文本 Markdown**——不锁在云端私有格式里（这正是下一课 Codex 能接管的原因，先埋钩子）
   - 双链 `[[]]` 与关系图谱，天然适配卡片盒笔记法
   - 插件生态丰富；个人使用免费（Sync / Publish 为官方付费服务）
2. **安装与 vault 创建**：一个 vault 就是一个普通文件夹；演示安装 → 新建 vault → 界面导览
3. **四个核心操作**：Markdown 基础语法、`[[双链]]` 与反向链接面板、`#标签`、每日笔记（Daily Notes）
4. **推荐目录骨架**（示范，供学员拷贝）：

   ```
   vault/
   ├── 00-Inbox/        # 所有未整理信息先进这里，只进不出（由整理流程清空）
   ├── 10-Projects/     # PARA-P
   ├── 20-Areas/        # PARA-Areas
   ├── 30-Resources/    # PARA-Resources
   ├── 40-Archives/     # PARA-Archives
   ├── 90-Templates/    # 笔记模板
   └── attachments/     # 图片等附件
   ```

5. **插件宁少勿多**（示例）：Templater（模板）、Dataview（查询）——先跑通核心流程，再谈插件

### 四、动手实操：搭建你的第一个 vault（7分钟）
1. 按课程骨架创建目录 → 写第一篇笔记 → 用 `[[]]` 链到第二篇 → 打开图谱看连线
2. 用每日笔记记一条今天的学习收获
3. **迁移策略讲解**：历史收藏不要一次性导入；新信息先进 Inbox，旧内容按需搬迁——避免开局即弃坑

### 五、收尾：从工具到系统（3分钟）
1. 本课小结：方法论选型 + Obsidian 四个核心操作 + 骨架落地
2. **下节课预告**：这个文件夹现在还只能靠你手动维护——下一课把它变成 Codex 的「项目」，让 AI 当你的知识库管理员

## 学员动手实践任务
1. 安装 Obsidian 并创建个人 vault，按课程骨架建好目录
2. 写 3 篇互相双链的笔记（主题就用本课的 PARA / 卡片盒 / MOC）
3. 用每日笔记记录今天课程收获

## 课后作业
1. 把本周工作/学习中至少 5 条零散信息捕获进 Inbox
2. 阅读 PARA 与卡片盒笔记法入门材料（见参考资源），在 vault 里写下你的选型判断与理由
