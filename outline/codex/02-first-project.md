# 第 2 课：第一个项目与核心工作流（30 分钟）

**对应教材**：《OpenAI Codex 从入门到精通》§03 你的第一个项目
**教学目标**：
1. 理解并复述 Codex 核心工作循环：Prompt → Plan → Execute → Verify
2. 以 md2html 命令行工具为例，完整走通从空目录到功能完整的开发闭环
3. 掌握三种沙盒模式的选择逻辑，养成「每步验证」的工作习惯
4. 学会基础的 TUI 操作：@ 引用文件、Enter 中途插话、Ctrl+C 中断

## 时间分配与内容大纲

### 一、上节回顾与本课目标（3分钟）
1. 回顾五形态与学员安装情况反馈
2. 收集课后作业中「最想解决的痛点」，衔接本课完整工作流的价值
3. 本课成果预告：一小时内产出一个带版本控制的完整 CLI 工具

### 二、为什么第一个项目如此重要（3分钟）
1. 第一印象决定工具采纳率——第一次体验糟糕多数人不会有第二次
2. 项目选择两原则：足够小（1 小时内完成）+ 足够完整（覆盖文件读写、逻辑处理、命令行交互）
3. 本课项目介绍：Markdown 转 HTML 命令行工具（md2html）
   ```bash
   mkdir md2html && cd md2html
   codex
   ```

### 三、核心循环四阶段精讲（7分钟）
1. **Prompt 阶段**：需求描述结构示范
   - 功能要求清单化：命令格式 `md2html input.md -o output.html`、支持的语法范围、默认样式、缺省输出名、`--watch` 参数
   - 技术约束明确化：「用 TypeScript 写，配置好 tsconfig 和 package.json」
2. **Plan 阶段**：观察 Codex 输出的计划清单（初始化依赖 → 主入口 → 解析逻辑 → watch 模式 → 构建配置 → 测试样例）
3. **两个决策动作**：批准执行 / 提出修改意见（示例：不用 marked 库改用正则实现）
4. **Execute 阶段**：看懂 diff 展示（绿色新增），浏览但不逐行审
5. **Verify 阶段**：创建测试样例 → 运行转换 → 浏览器查看 HTML 效果 → 循环迭代
6. **新手最常见的错误：过度规划**——先让它跑一遍看到结果再调整

### 四、三种安全模式实操对比（7分钟）
1. **read-only**（`--sandbox read-only`）：只读不写，适合代码审查、提问
2. **Auto / full-auto**（`--full-auto`）：工作区内自由读写+按需审批，日常开发推荐
3. **full-access**（`--yolo`）：无限制含网络，仅在隔离测试环境使用（安全红线，第 3 课展开 Windows 删盘事件）
4. 常见问题现场解答：
   - 「无法访问网络」提示的处理：按需授权 / `/permissions` 会话内切换
   - 生成的代码有 Bug：直接把错误信息贴回去让 Codex 修
   - 执行卡住：Ctrl+C 中断后重新描述，Codex「不会记仇」

### 五、完整实战：从零到 v0.1.0（7分钟）
学员跟做，讲师同步演示：
1. 发出首个结构化 Prompt 建立 md2html 基础版
2. 创建 sample.md 测试文件并验证输出 HTML
3. 提出迭代需求：暗色代码高亮主题、嵌套列表层级样式修正
4. 追加进阶功能：`--watch` 监听重转、`--css custom.css` 自定义样式、`--serve` 本地预览服务器
5. 让 Codex 编写 README.md 说明文档
6. 初始化 Git 并完成首次提交：
   ```
   git init && .gitignore(node_modules/dist) && commit "Initial commit: md2html CLI tool"
   ```

### 六、TUI 三板斧与小技巧（3分钟）
1. `@` 引用文件：模糊搜索快速引用工作区路径
2. Enter 中途插话：不必等它做完就能补充指令
3. Ctrl+C 中断当前操作
4. 进阶预告：Esc Esc 回溯编辑、Tab 排队任务（第 3 课详解）

## 本课课堂演示清单
- 从 mkdir 到首次 commit 的全流程实录（约 6 分钟压缩演示）
- Plan 阶段的中途修改计划演示

## 学员动手实践任务
1. 跟随课程完成 md2html 工具的基础版本并通过浏览器验证
2. 至少完成一次「提出样式迭代意见 → 验证修改生效」的循环
3. 完成进阶功能中的任意两项（watch / css / serve）
4. 完成 Git 初始化与规范 commit message 的提交

## 课后作业
1. 为你的 md2html 工具新增一个课堂上未提及的功能（如表格语法支持、多文件批量转换）
2. 用 Codex 对作业结果做一轮自检并记录修复过程
3. 阅读《OpenAI Codex 从入门到精通》§03 全章
