# OpenAI Codex 从入门到精通（教学课程）

**课程版本**：v1.1（基于《OpenAI Codex 从入门到精通 v2.0.1》橙皮书编写）
**适用教材版本**：Codex CLI 0.130+ · 模型 GPT-5.5 / GPT-5.4 / GPT-5.4-mini
**总课时数**：8 课时 × 30 分钟 = 4 学时
**目标受众**：工程师、产品经理、独立开发者，以及希望掌握 AI 编程工作流的技术从业者

---

## 课程定位

本课程以《OpenAI Codex 从入门到精通》为教材，帮助学员系统掌握 Codex 五种形态（CLI / 桌面 App / Cloud 云端 / IDE 扩展 / Chrome 扩展）的使用方法与组合策略。课程采用「讲授 + 演示 + 动手实战」的形式，每个课时包含完整的课前准备、分段时间安排、核心知识点、课堂演示与课后作业。

学员完成全部课程后，应能独立完成：从零搭建 Codex 工作环境 → 用 CLI 完成完整开发循环 → 配置 AGENTS.md 项目规则 → 使用桌面 App 多 Agent 并行开发 → 用云端异步委派批量任务 → 通过 Skills/MCP/Automations//goal 构建自动化长任务系统，并最终综合运用以上能力交付一个完整产品。

> **30 分钟课时版说明**：本课程按每课时 30 分钟设计，各章节时长由原 90 分钟版本等比压缩重新分配，教学大纲内容保持不变。因课堂时间有限，部分动手任务自然延伸为课后作业；第 8 课综合实战在课内完成五阶段路线推演与关键决策讲解，完整开发作为毕业实战课后延续。

## 教学主线

三条主线贯穿全程：

1. **形态主线**：CLI → App → Cloud → IDE/Chrome 扩展，由单一形态逐步扩展到多形态协作。
2. **能力主线**：单次对话 → 项目规则 → 多Agent并行 → 异步委派 → 自动化长任务。
3. **安全主线**：沙盒模式 → Auto-review → Full Access 风险边界，每个实操环节都强调权限边界意识。

## 教学整体建议

1. **30 分钟节奏提示**：每课时按「导入回顾（3）+ 核心讲授与演示（17~20）+ 快速实操或讨论（5~8）+ 收尾预告（2）」推进，具体以各课时分段为准；讲授环节务必提前演练，避免现场耗时超支。
2. 学员环境要求统一前置检查：ChatGPT Plus 及以上账号、Node.js 18+、可访问 OpenAI 服务。涉及网络受限环境的注意事项见第 1 课附录部分及教材附录C。**安装等待类操作尽量在课前完成或改为讲师演示。**
3. 安全红线贯穿始终：任何平台不开 `full-access`；Windows 环境强制只使用 `workspace-write` 或 `read-only`；实操前先确认 Git 干净状态或已备份。
4. AI 编程工具迭代极快（教材半年一修），授课时请核对当时的官方 Changelog，对模型名、定价等内容以官方文档为准。
5. 课程作业采取累积式设计：第 2~8 课的实战任务共同服务于第 8 课的综合项目，建议学员始终维护同一个练习仓库；因课堂时间有限，动手完成度依赖课后作业跟进，需明确结课交付标准。
