# OpenAI Codex 从入门到精通（教学课程）

**课程版本**：v1.6（基于《OpenAI Codex 从入门到精通 v2.0.1》橙皮书编写；v1.2 新增个人知识库模块，v1.3 新增内容创作实战篇，v1.4 综合实战拆分为三课时，v1.5 课程重组为两篇结构，v1.6 内容创作每场景扩为三课时）
**适用教材版本**：Codex CLI 0.130+ · 模型 GPT-5.5 / GPT-5.4 / GPT-5.4-mini
**总课时数**：25 课时 × 30 分钟 = 12.5 学时
**目标受众**：工程师、产品经理、独立开发者，以及希望掌握 AI 编程工作流的技术从业者

---

## 课程定位

本课程以《OpenAI Codex 从入门到精通》为教材，帮助学员系统掌握 Codex 五种形态（CLI / 桌面 App / Cloud 云端 / IDE 扩展 / Chrome 扩展）的使用方法与组合策略。课程采用「讲授 + 演示 + 动手实战」的形式，每个课时包含完整的课前准备、分段时间安排、核心知识点、课堂演示与课后作业。

学员完成全部课程后，应能独立完成：从零搭建 Codex 工作环境 → 用 CLI 完成完整开发循环 → 配置 AGENTS.md 项目规则 → 使用桌面 App 多 Agent 并行开发 → 用云端异步委派批量任务 → 通过 Skills/MCP/Automations//goal 构建自动化长任务系统 → 结合 Obsidian 搭建由 AI 维护的个人知识库 → 综合运用以上能力交付一个完整的静态网站项目，并进一步把这套工作流迁移到公众号写作、小红书图文、AI 生图与 AI 生视频等日常内容生产场景。

> **30 分钟课时版说明**：本课程按每课时 30 分钟设计，各章节时长由原 90 分钟版本等比压缩重新分配，教学大纲内容保持不变。因课堂时间有限，部分动手任务自然延伸为课后作业；实战篇开篇的静态网站综合实战（第 11~13 课）按「规划 → 开发 → 上线交付」三段推进，课内完成关键决策讲解与核心开发演示，完整开发作为毕业实战课后延续。第 8~10 课「个人知识库」模块为 v1.2 新增，第 14~25 课「内容创作实战」模块为 v1.3 新增（v1.6 起每场景由 2 课时扩为 3 课时），均按 30 分钟节奏原生编写。

## 课程结构总览

## 教学主线

三条主线贯穿两篇：

1. **形态主线**（基础篇）：CLI → App → Cloud → IDE/Chrome 扩展，由单一形态逐步扩展到多形态协作。
2. **能力主线**（基础篇 → 实战篇）：单次对话 → 项目规则 → 多Agent并行 → 异步委派 → 自动化长任务 → 真实场景交付。
3. **安全主线**（全课程）：沙盒模式 → Auto-review → Full Access 风险边界，每个实操环节都强调权限边界意识。
4. **实战主线**（实战篇）：静态网站综合项目 → 公众号 → 小红书 → 生图 → 生视频，实战场景均按「上·认知与规则 / 中·产出与打磨 / 下·发布与运营」的三段节奏推进，把基础篇的编码能力迁移到完整产品交付与内容生产领域。

## 教学整体建议

1. **30 分钟节奏提示**：每课时按「导入回顾（3）+ 核心讲授与演示（17~20）+ 快速实操或讨论（5~8）+ 收尾预告（2）」推进，具体以各课时分段为准；讲授环节务必提前演练，避免现场耗时超支。
2. 学员环境要求统一前置检查：ChatGPT Plus 及以上账号、Node.js 18+、可访问 OpenAI 服务。涉及网络受限环境的注意事项见第 1 课附录部分及教材附录C。**安装等待类操作尽量在课前完成或改为讲师演示。**
3. 安全红线贯穿始终：任何平台不开 `full-access`；Windows 环境强制只使用 `workspace-write` 或 `read-only`；实操前先确认 Git 干净状态或已备份。
4. AI 编程工具迭代极快（教材半年一修），授课时请核对当时的官方 Changelog，对模型名、定价等内容以官方文档为准。
5. 课程作业采取累积式设计：基础篇（第 2~10 课）的实战任务共同服务于实战篇开篇的静态网站综合项目，建议学员始终维护同一个练习仓库；因课堂时间有限，动手完成度依赖课后作业跟进，需明确结课交付标准。
6. **实战篇（第 11~25 课）环境准备**：综合实战无需额外第三方服务；内容创作场景涉及第三方内容平台与生成服务（公众号/小红书平台权限、生图与视频模型 API），各场景课前需完成 API Key 配置与账号授权；平台政策与计费变动较快，授课前请核对当时的官方说明。**生成类任务单次耗时可能超过课时时长，建议课内出小样、课后批量完成。**小白学员建议每场景把「中·产出与打磨」环节适当拉长，预留缓冲，避免赶进度。
