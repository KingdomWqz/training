# 第 1 课：文生图——从文字到图像（30 分钟）

**教学目标**：
1. 理解 AI 生图工具带来的范式变化，说清文生图能做什么、不能做什么
2. 掌握主流文生图模型（国际 + 国内）的能力差异与选型方法
3. 掌握「主体+细节+环境+构图+光线+风格+画质词」提示词公式，能独立写出结构化提示词
4. 了解模型商用授权与平台合规的底线，建立版权意识

## 时间分配与内容大纲

### 一、AI 生图认知：范式变化与能力边界（4分钟）
1. **范式变化**：搜图（找到别人拍的）→ 作图（自己画/PS）→ 生成（一句话让模型画出来）
2. **文生图能做什么**
   - 秒级出图，支持快速 AB 测试不同创意方向
   - 场景不受物理限制：「把商品放进任何环境」
   - 边际成本低，适合小批量、多 SKU 店铺与内容矩阵
3. **文生图不能做什么（本课重点认知）**
   - 商品外观不可控：文字描述的「一致性」天然弱，易出现「换了个产品」
   - 复杂文字渲染仍易翻车：多语言文字尤其如此
   - 精细化修改弱：生成后想改局部，靠的是后续的图生图与修图能力
   - 结论：文生图负责「从 0 到 1 的创意发散」，严格还原交给图生图，精修交给修图（第 2、3 课）

### 二、主流文生图模型全景与选型（7分钟）
1. **国际主流模型**
   - **Midjourney**：光影质感与艺术氛围突出，适合生活方式场景图
   - **GPT Image（ChatGPT）**：自然语言指令理解强，支持对话式改图
   - **Nano Banana（Gemini）**：图像编辑与多图一致性能力优秀，细节还原强
   - **Flux / Stable Diffusion**：开源可控，可本地部署、训练专属商品 LoRA 模型
2. **国内主流模型**
   - **即梦AI（字节 Seedream）**：中文语义理解好，图中渲染中文文字准确率高
   - **通义万相（阿里）**：与淘系生态结合紧密，提供电商模板与工作流
   - **腾讯混元、文心一格**等：可作为备选补充
3. **选型决策参考**

   | 需求场景 | 推荐方案 |
   |----------|----------|
   | 海报需要准确中文文案 | 即梦AI、GPT Image |
   | 强调质感与氛围的场景图 | Midjourney |
   | 多张图商品外观一致 | Nano Banana、即梦参考图、GPT Image |
   | 数据安全、批量定制 | 本地部署 Flux/SD |
   | 零基础、想要最省心 | 即梦AI（中文界面 + 模板多） |

4. **版权与平台合规提醒**（讲一句留个印象，第 6 课再展开肖像权）
   - 商用前确认所选模型与生成内容的商用授权条款
   - 关注电商平台对 AI 生成内容的标识要求，避免虚假宣传风险

### 三、提示词工程：写出能出好图的提示词（10分钟）
1. **通用提示词公式**
   `主体 + 细节特征 + 环境背景 + 构图视角 + 光线氛围 + 风格 + 画质词`
2. **示例拆解**
   「一只*主体*磨砂质感白色保温杯*细节*，放在原木色桌面*环境*，正面 45 度俯拍*构图*，清晨柔和侧光*光线*，日系简约风*风格*，商业摄影级画质*画质词*」
3. **电商场景的关键控制点**
   - **主体排第一**：先写清楚「卖的是什么」，细节决定是否「像本人」
   - **构图要给文案留白**：封面图画面留白位置，是给促销标签、标题用的
   - **比例与用途挂钩**：主图 1:1（建议 800×800px 以上）、Banner 16:9 或 3:1、小红书封面 3:4
4. **反向提示词与常见翻车点**
   - 排除项：多余手指、扭曲文字、杂乱背景、水印
   - 典型问题：商品变形、颜色偏差、文字乱码——分别对应什么规避写法
   - 记住：**文字改坏比图形改坏更普遍**，大段文字不要指望原生生成
5. **参数初识**：比例（Aspect Ratio）、风格强度、种子（Seed）在一致性中的作用——留到第 2 课细讲

### 四、课堂演示：弱提示词 vs 结构化提示词（4分钟）
1. 同一商品用弱提示词「一个保温杯」vs 结构化提示词各出 1 张，直观感受差距
2. 对比「换了个产品」与「是否贴合商品」两种结果，引出第 2 课垫图的必要性

### 五、实操与收尾（5分钟）
1. 学员用自己（或讲师提供）的样例商品，套用公式写出结构化提示词并出 2 张图
2. 小结：文生图 = 创意发散 + 提示词公式；一致性不足是先天短板，交给后两课补齐
3. 预告：下一课讲图生图，解决「商品换了个样」的问题

## 本课课堂演示清单
- 范式对比：一张商品图「搜索 vs 手工制作 vs AI 生成」的差异
- 弱提示词 vs 结构化提示词的出图对比（同商品）
- 即梦AI（或任一国内模型）从注册登录到首次出图的完整流程

## 学员动手实践任务
1. 完成至少一个生图工具的注册登录，跑通「输入 → 出图」的最小闭环
2. 用自己的样例商品，套用提示词公式写出结构化提示词，出 2 张图
3. 选一张最满意的，反向检查「商品是否变形、文字是否翻车」，记录翻车点对应的规避写法

## 课后作业
- 用同一套提示词公式，分别产出一张「主图比例 1:1」和一张「小红书 3:4」的商品图，对比比例对构图的影响
- 建立自己的提示词模板表，把本课公式 + 常用画质词/风格词抄录下来，后续课时持续扩充

## 教学准备清单
- [ ] 讲师提前注册、充值时并测试至少 1 个国内 + 1 个国际生图模型账号

- [ ] 准备对比案例图：弱提示词 vs 结构化提示词的出图差异
- [ ] 测试网络环境，确认海外模型可正常访问
- [ ] 准备提示词模板表（打印或在线文档分享）
- [ ] 测试投影/屏幕共享功能
