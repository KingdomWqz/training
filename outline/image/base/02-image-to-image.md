# 第 2 课：图生图——用参考图控制生成（30 分钟）

**教学目标**：
1. 理解图生图的核心价值：用一张参考图（垫图）锁住「商品本人」
2. 掌握垫图/参考图的操作方法与参数（权重、多图参考）
3. 掌握高频图生图玩法：相似图、风格迁移、换背景、扩图
4. 为第 4~6 课电商场景的商品一致性控制打下基础

## 时间分配与内容大纲

### 一、图生图原理与三大用途（4分钟）
1. **原理一句话**：以一张已有图片为输入，生成与之「相关」但改变某些属性的新图；商品实拍图成为稳定锚点
2. **三大用途**
   - **垫图改图**：保持主体，换背景/换风格/改氛围
   - **相似图**：以图找图，产出主体一致的多个候选方案
   - **为修图做准备**：局部编辑（第 3 课）本质是「局部图生图」——选定区域重绘
3. **能力定位**：文生图负责从 0 到 1 的发散，图生图负责把产品「钉」在画面上

### 二、参考图一致性：把商品锁在画面里（8分钟）
1. **为什么要垫图**：提示词是文字，模型对商品的「手指、颜色、材质、形状」没有真实记忆；实拍图自带这些信息
2. **操作要点**
   - 上传一张清晰的商品实拍图（光线均匀、主体完整的原图效果最好）
   - 多数工具支持「参考图 + 文字指令」：文字负责场景与风格，参考图负责商品本体
   - 权重/相似度参数：调高更还原、调低更自由，电商场景默认沿着「还原优先」调
3. **多参考图**：衣、包、鞋等多件套商品，可同时传多张参考图，锁定多个对象
4. **常见坑**
   - 参考图不清晰/主体太小 → 还原失败
   - 权重过高的僵硬感 → 商品像「贴图」，需要平衡
   - 多对象时方向/摆放变形 → 逐张检查再合成
5. **种子（Seed）概念**：同一提示词 + 同一 Seed 可复现构图，用于批量出多张候选再择优

### 三、常见图生图玩法拆解（8分钟）
1. **换背景**：白底实拍 → 室内/户外/舞台背景（实战篇第 5 课的核心动作）
2. **风格迁移**：实拍 → 手绘风、插画风、质感大片风（小红书/品牌宣传常用）
3. **相似图/多方案**：同一商品生成多个角度、多个搭配的候选图
4. **扩图（Outpainting）**：把 1:1 竖版扩展成 3:4/16:9，把「图上没有」的地方补齐（构图延伸，直播/封面用）
5. **再生成文字**：替换图中的文案/水印区域，配合清除后再补字

### 四、课堂演示：实拍图 → 保持商品的场景图（5分钟）
1. 上传保温杯实拍图，写指令「保持杯身外观不变，放到秋日露营桌上，暖色晨光，生活方式摄影」
2. 对比上一课纯文生图的同一场景，观察商品是否「跑样」
3. 现场调一次权重：高还原 vs 高创意的差异演示

### 五、实操与收尾（5分钟）
1. 学员对上一课的样例商品执行「实拍垫图 + 换背景」与「相似图」各 1 次
2. 小结：图生图 = 「文字定场景、图片定商品」，一致性是电商出图的生命线
3. 预告：下一课修图，把成图里多出来的手指、乱码文字、杂物清掉

## 本课课堂演示清单
- 同一场景「纯文生图 vs 垫图图生图」的商品还原度对比
- 参考图权重高/低的差异实时演示
- 扩图（1:1 → 16:9）补齐构图延伸的演示

## 学员动手实践任务
1. 用自己的商品实拍图，垫图生成 1 张背景替换图（如白底 → 室内场景）
2. 生成 2 张相似图候选，对比与商品原图的还原度
3. 尝试一次扩图，把竖版图扩展为横版，检查扩展区域是否自然

## 课后作业
- 用一张商品图分别生成「高还原」「中等」「高创意」三档权重各 1 张，记录权重手感
- 收集 2 张自己店铺或同行爆款场景图，反推它们的「垫图 + 指令」组合怎么写
