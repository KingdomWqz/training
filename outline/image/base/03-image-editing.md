# 第 3 课：修图——AI 编辑与精修（30 分钟）

**教学目标**：
1. 理解 AI 修图能做什么、不能做什么，与传统修图工具的分工边界
2. 掌握局部重绘、消除、抠图、扩图、高清放大五大核心操作
3. 掌握「AI 出底图 + 设计工具加字/合成」的电商后期工作流
4. 会用上架检查清单判断成图是否达到上架标准

## 时间分配与内容大纲

### 一、AI 修图能做什么、不能做什么（3分钟）
1. **能**：去瑕疵（多余手指、杂物、水印）、换背景、微调颜色与光线、扩图补全、清晰化放大
2. **不能/要小心**：精细的版式设计（字号、对齐、图层）、带来真实感的商品尺码与结构改动、大段精确文字排版
3. **定位**：AI 负责「让图像干净可信」，设计与文案叠加交给设计工具——两者是组合关系不是竞争关系

### 二、五大核心修图操作精讲（10分钟）
1. **局部重绘（Inpainting）**：圈选区域重绘
   - 用途：修手指、改局部图案、替换小物件；电商典型场景是「把桌面杂物抹掉，让主角更聚焦」
   - 操作：涂抹蒙版 → 提示词描述「这里应该是什么」→ 调整影响范围
2. **消除（Erase/移除）**：一键移除路人、水印、日期、电线等无关元素
   - 与局部重绘的区别：消除更「无痕」，适合小面积清理
3. **抠图换背景**：自动识别主体抠出 → 换白底 / 纯色 / 场景底
   - 电商刚需：实拍背景不干净时一键换白底主图
4. **扩图（Outpainting）**：第 2 课已见，这里强调它对「错误边缘」的修补——重算裁切、补齐比例
5. **高清放大（Upscale/增强）**：把低清/小图放大到平台要求尺寸，让商品纹理更清晰

### 三、电商修图高频场景（7分钟）
1. **去瑕疵三连**：多余手指、商品反光杂点、背景杂物
2. **去水印/去牛皮癣**：清理竞品水印、自家历史角标，注意素材版权边界
3. **统一背景规范**：多 SKU 统一白底/同色背景，保证店铺视觉整齐
4. **文字处理策略**：大段营销文字交给 Canva/稿定设计等工具叠加；AI 只负责干净底图
5. **组合流程示例**：AI 生成场景底图 → 局部重绘清杂物 → 抠图贴上白底产品 → 设计工具加促销角标与标题

### 四、课堂演示与实操：修一张翻车主图（6分钟）
1. 讲师演示：一张「手指多余 + 背景杂乱 + 文字乱码」的翻车主图，走完「消除 → 局部重绘 → 抠图换底」三步
2. 学员动手：对自己的（或讲师提供的）一张成图完成至少 2 项修图操作
3. 讲评：修图目标是「干净可信」，不是「过度美化」，避免实物与图中不符引发售后

### 五、收尾：上架前检查清单（4分钟）
1. **快速检查清单**
   - 商品外观与实物是否一致（颜色/结构/比例，避免售后纠纷）
   - 是否符合平台主图规范（无牛皮癣、无违规水印、尺寸达标）
   - AI 生成内容是否需要按平台规则标注
2. **小结与预告**：三项基础能力已齐（文生图发散、图生图锁形、修图出成品）；下一课开始，把它们组合起来做电商真实交付

## 本课课堂演示清单
- 翻车主图「消除 → 局部重绘 → 抠图换底」三步修复全过程
- 局部重绘影响范围大小（过大/过小）的对比演示
- 高清放大前后对比（放大后商品纹理细节可辨）

## 学员动手实践任务
1. 用消除工具移除一张图中的路人/杂物/水印
2. 用局部重绘修复一处瑕疵（如多余手指、褶皱、划痕）
3. 把一张实拍图抠图换白底，作为后续课时的主图素材

## 课后作业
- 整理一张「上架前检查清单」，为后续两课（场景图、模特换装）产出物做自检
- 体验一次「AI 出底图 + Canva/稿定加字」的完整组合流程，产出 1 张带促销文字的海报底稿
