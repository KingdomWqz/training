# 第 6 课：电商实战·模特换装（30 分钟）

**教学目标**：
1. 理解模特换装/虚拟模特的应用价值：无实拍成本批量出「有人穿」的服装图
2. 掌握服装鞋包类商品「平铺图 → 虚拟模特上身」的主流做法
3. 了解真人模特照片换装的方法与边界
4. 清楚肖像权、AI 模特标识等合规红线，能规避风险使用

## 时间分配与内容大纲

### 一、模特换装的应用场景与价值（4分钟）
1. **痛点**：服装鞋包电商的实拍要模特、场地、摄影，上新慢、成本高；不是所有款式都来得及拍模特图
2. **AI 的价值**：平铺图/白底图 → 一键上身虚拟模特，覆盖多尺码、多身材、多场景，支撑大促快速上新
3. **常用产出物**
   - 服装/鞋/包/配饰的「模特上身图」（细节图、场景图）
   - 同一款式多颜色、多尺码的规格图
   - 详情页真人感展示、社交媒体种草图

### 二、方案一：平铺图 → 虚拟模特上身（10分钟）
1. **主流做法**（按工具分为两类）
   - 成品工具：即梦AI 人物/虚拟模特、淘宝/拼多多商家后台 AI 模特、美图云修等——上传商品图，选模特身材/场景/动作，一键出图
   - 自定义做法：SD/Flux 结合 ControlNet 姿势控制 + IP-Adapter 服装保留（或局部重绘蒙版），精细控制姿势与服装版型
2. **操作要点**
   - 商品图要清晰、版型完整（平铺图/挂拍图比皱巴巴的实拍更好用）
   - 先定模特（身材/气质）再定动作与场景，保持服装「版型和颜色」不跑样
   - 多颜色款：锁定版型，只替换颜色，一次性批量出规格图
3. **常见翻车与补救**
   - 服装版型变形、Logo 糊掉 → 用第 2 课垫图/第 3 课局部重绘修正
   - 多颜色批量不一致 → 用「同一模板 + 换色」保证统一
4. 学员动手：用一款服装/鞋包商品产出 1 张虚拟模特上身图

### 三、方案二：真人模特换装及其边界（6分钟）
1. **做法**：用真人模特照片换装（保留脸/身体，替换衣服），适合「同一位主推模特换多款」
2. **边界与风险（重点）**
   - **不可对未授权真人进行换装**：未经模特/权利人同意使用其肖像，涉嫌侵犯肖像权
   - 名人/网红脸即使「换掉衣服」也不可控地携带肖像权风险
   - 使用自有实拍模特、或购买有授权的人像素材，才可进行换装
3. **与方案一的分工**：需要真人脸与气质 → 方案二（自持肖像）；只需「有人穿起来的样子」 → 方案一更安全省心

### 四、合规红线与平台要求（4分钟）
1. **肖像权**：任何真人面孔必须取得授权；无法确认来源的素材一律不用
2. **AI 模特标识**：关注平台对「AI 生成/虚拟模特」的标识或标注要求，避免误导消费者构成虚假宣传
3. **商品一致性**：图中展示的版型、颜色与实际发货商品必须一致，否则客服与退货压力大
4. **选型合规**：确认所选工具的商用条款；本地部署模型时同样遵守生成内容的使用规范

### 五、实操任务与收尾（6分钟）
1. 学员完成「虚拟模特上身图 1 张 + 真人换装（自有素材）1 张（选做）」
2. 验收清单：服装版型/颜色是否与商品一致？有无多余肢体/变形？是否已确认素材肖像授权？是否按平台规则标注 AI 内容？
3. 全课程收尾：回顾六课时主线——文生图发散 → 图生图锁形 → 修图出成品 → 封面图抓点击 → 场景图促转化 → 模特图破成本；学员回到自己店铺，按「商品 5 张主图 + 场景矩阵 + 模特图」的组合规划后续运用

## 本课课堂演示清单
- 平铺图 → 虚拟模特上身（成品工具）完整操作
- 同一款式多颜色的「锁版型 + 换色」批量出图演示
- 多手指/变形翻车案例 + 局部重绘补救

## 学员动手实践任务
1. 用一款服装或鞋包商品，产出 1 张虚拟模特上身图
2. （选做）用自有授权的模特图完成 1 次真人换装，体验其效果与风险取舍
3. 用验收清单自检，记录商品一致性、合规两项的检查结果

## 课后作业
- 为同一款服饰产出「3 个不同场景」的模特图，构建一个小型场景矩阵
- 梳理自己店铺的合规清单：哪些素材有授权、哪些图需 AI 标注，形成可执行的制度

## 教学准备清单
- [ ] 讲师提前试跑虚拟模特工具（确认款式的版型还原度与速度）
- [ ] 准备 1 组多颜色同款的商品图（演示锁版型批量换色）
- [ ] 准备肖像权风险的反面案例（未授权换装/名人脸）用于讲清红线
- [ ] 准备合规自查清单（发给学员课后使用）
