# 第 4 课：电商实战·封面图（30 分钟）

**教学目标**：
1. 掌握电商平台封面图（主图）的尺寸、比例与规范要求
2. 用提示词公式 + 垫图锁定商品外观，快速产出可上架的白底主图
3. 掌握「AI 出背景 + 设计工具加字」的促销海报流程
4. 了解小红书/详情页封面的延伸应用

## 时间分配与内容大纲

### 一、电商封面图的类型与平台规范（5分钟）
1. **封面图家族**：白底主图、促销海报、详情页首屏、小红书封面——同是「封面」，规格与用途差异很大

   | 类型 | 常用比例 | 用途 |
   |------|----------|------|
   | 平台主图 | 1:1（建议 800×800px 以上） | 搜索结果第一印象，抓眼球 |
   | 促销海报 | 16:9 / 3:1 | 活动页、Banner、预热素材 |
   | 详情页首屏 | 3:4 竖版为主 | 承接主图点击，讲卖点 |
   | 小红书封面 | 3:4 | 笔记第一屏，决定打开率 |

2. **主图规范红线**（以淘宝/天猫为例，其余平台授课时核对）
   - 无牛皮癣（大块促销文字贴满、边框压字）、无水印、无违规标识
   - 商品主体完整、不偏、不成"贴图感"，背景干净
   - 「文字多的图 = 应发布违规高风险」，标题文案尽量后期叠加
3. **一套图逻辑**：5 张主图各有分工——白底（规范）→ 卖点特写 → 场景（第 5 课）→ 细节 → 促销/售后承诺

### 二、白底主图：公式与实操（8分钟）
1. **公式**（组合第 1 课公式 + 第 2 课垫图）
   `参考图（实拍/白底原图）+ 纯白背景 + 产品居中 45 度角 + 影棚柔光箱布光 + 底部轻微自然倒影 + 商业产品摄影 + 超高清晰度`
2. **垫图优先**：有实拍图先垫图，保证颜色/材质/形状与实物一致，避免「换了个产品」
3. **实操要点**
   - 一次生成 4 张择优；反复垫图直到商品还原度满意
   - 背景要「纯而不死」：轻微渐变/自然倒影可提升质感，但必须与平台审核规则兼容
   - 比例固定 1:1，用第 3 课的放大功能提到 800×800px 以上
4. 学员动手：为自己的商品（或样例商品）产出 1 张白底主图

### 三、促销海报：AI 出背景 + 工具加字（7分钟）
1. **为什么不在图里生成大段文字**：模型多语言文字渲染翻车率高，且平台对「图内文字」审核严
2. **推荐流程**：AI 生成干净背景/氛围底图（留白给文字）→ 设计工具叠加标题、价格、倒计时 → 导出
3. **提示词示例**：`618 年中大促竖版海报氛围底图，红色喜庆渐变背景，金色礼品盒堆叠悬浮，画面上方留白区域用于加字，电商大促视觉风格`
4. 要点讲评：留白位置、主色调、与品牌色一致；底部倒计时等元素后期加，方便改价复用
5. 学员动手：生成 1 张促销背景图并叠加 2~3 个文字元素

### 四、小红书/详情页封面延伸（4分钟）
1. **小红书封面**：3:4 竖版，核心是「一眼看懂商品 + 一个钩子」，文字 3~8 字为宜，图片本身要耐看
2. **详情页首屏**：把主图卖点讲深一层，可做成「局部特写 / 成分图 / 对比图」
3. 提醒：封面图是点击率战场，多用多方案 AB 测试，不要一次定稿

### 五、实操任务与收尾（6分钟）
1. 学员完成「白底主图 1 张 + 促销海报底图 1 张」，按检查清单自检
2. 快速检查清单：商品是否与实物一致？比例是否符合平台？文字是否干净可读？有无牛皮癣/水印？
3. 小结与预告：封面图解决「抓住点击」，下一课生活场景图解决「讲清使用场景、促进转化」

## 本课课堂演示清单
- 一套 5 张主图的「分工逻辑」示意图
- 白底主图「垫图 → 出 4 张 → 择优 → 放大」全流程
- 促销海报「AI 底图 → 加字」组合流程演示

## 学员动手实践任务
1. 用自己的商品产出一张符合平台规范的白底主图（1:1，≥800px）
2. 产出一张促销海报背景图，并用设计工具叠加标题与价格标签
3. 用第 3 课的检查清单对两张图自检，记录不符合项与修改动作

## 课后作业
- 为同一商品产出 2 张不同促销风格的海报底图，按「留白/主色/氛围」三点评比
- 收集同行业 5 张爆款主图，反推其「垫图基础 + 构图 + 留白」写法，纳入自己的模板表
