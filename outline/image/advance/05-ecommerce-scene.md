# 第 5 课：电商实战·生活场景图（30 分钟）

**教学目标**：
1. 理解生活场景图（种草/氛围图）在转化链路中的价值与使用位置
2. 掌握「实拍垫图 + 换场景」的一致性流程，让商品在不跑样的前提下进入目标生活场景
3. 能按目标客群匹配场景语境，避免「商品被场景吞掉主体地位」
4. 综合运用第 1~3 课能力完成一张场景图的出图、修图、定稿

## 时间分配与内容大纲

### 一、生活场景图的价值与使用位置（4分钟）
1. **为什么需要场景图**：白底主图讲「这是什么」，场景图讲「你能用它过上怎样的生活」——后者带来情绪价值与溢价
2. **使用位置**
   - 主图第 3 张、详情页中段（使用展示）
   - 小红书/抖音种草图（氛围 > 参数）
   - 直通车/引力魔方广告图、直播间氛围背景
3. **对比案例**：同一保温杯「白底主图 vs 露营场景图」的点击与转化差异直觉

### 二、客群 × 场景 匹配矩阵（6分钟）
1. **先定客群再定场景**：母婴、数码、家居、美妆、户外各有各自的语境——给母婴产品配酒吧场景就是「语境错乱」
2. **常用场景类型**：

   | 品类 | 高转化场景示例 |
   |------|----------------|
   | 母婴 | 温馨客厅、亲子互动、晨光卧室 |
   | 数码 | 极简桌面、办公室、书房夜间氛围 |
   | 家居 | 原木餐桌、阳台午后、厨卫场景 |
   | 美妆 | 梳妆台、浴室暖光、旅行化妆包 |
   | 户外/运动 | 露营、晨跑、通勤地铁 |

3. **要素排序**：客群匹配 > 光线氛围 > 构图高级感——先对路，再好看

### 三、一致性流程：垫图 → 换背景 → 调光调氛（10分钟）
1. **标准流程**（复用第 2 课）
   - 第 1 步 垫图：上传实拍图，写场景指令，商品外观保持「原样」
   - 第 2 步 检查主体：商品是否变形、颜色是否跑偏、是否被场景「吞掉」——不达标就调权重/重试
   - 第 3 步 换角度出多张：一次多个构图候选，择优
2. **场景指令写法**：场景要素（什么环境）＋ 光线（什么时间什么光）＋ 氛围（生活气息）＋ 画质（生活方式摄影/浅景深）
   - 示例：「秋日清晨的木纹餐桌，白色陶瓷马克杯冒着热气，旁边放牛角包和一本摊开的杂志，暖金色自然光从左侧窗户洒入，浅景深，生活方式摄影」
3. **种草图进阶**：加入人的局部（手/侧影）增强代入感，但注意手指质量（第 3 课修图兜底）
4. **批量做法**：一个商品套用多个场景模板批量出，做「场景矩阵」，覆盖不同投放渠道

### 四、课堂演示：保温杯实拍 → 露营场景图（5分钟）
1. 现场走一遍「垫图 → 露营场景指令 → 出 4 张 → 挑选 → 修掉杂物」全流程
2. 对比上一课白底主图，讲清「同一商品、同一工具、不同目的」的用法差异

### 五、实操任务与收尾（5分钟）
1. 学员为自己的商品产出 1 张生活场景图（按自己客群自选场景），并按检查清单验收
2. 检查清单：商品没跑样？场景与客群匹配？主体地位清楚？光线/氛围合格？需要修图的地方？
3. 小结与预告：场景图讲「用起来的样子」；下一课模特换装，解决服装鞋包「没有人穿」的问题

## 本课课堂演示清单
- 「白底主图 vs 露营场景图」同商品对比
- 客群 × 场景匹配矩阵讲解（母婴全配错案例演示）
- 保温杯露营场景图「垫图 → 出图 → 修图」完整流程

## 学员动手实践任务
1. 用垫图为自己的商品产出 1 张与客群匹配的生活场景图
2. 检查并记录：商品是否跑样、主体是否被场景吞掉；跑样则调权重重试一次
3. 用第 3 课的修图能力给场景图去一处杂物或加高清放大

## 课后作业
- 同一商品生成 2 个不同生活场景（如「晨光餐桌」「户外露营」），对比哪个更配自己客群
- 收集 3 张同品类的高赞种草图，反推其「场景要素 + 光线 + 氛围」写法入模板表
