# 第 2 课 · 带货脚本与分镜设计

**时长**：30 分钟　**产出**：一条 30 秒脚本、6~8 镜分镜表

## 课时目标

- 掌握「黄金 3 秒钩子 → 痛点共鸣 → 卖点展示 → 信任背书 → CTA」五段式结构。
- 用 LLM 生成、比较和迭代口播台词。
- 把台词转成可执行的画面提示词和分镜表。

## 时间与内容

| 环节 | 时间 | 内容 |
|------|------|------|
| 导入回顾 | 3 分钟 | 复盘工具选型，拆解一条爆款视频前 3 秒 |
| 讲授与演示 | 18 分钟 | 五段式公式、30 秒节奏（约 120~150 字）、LLM Prompt、分镜字段 |
| 动手任务 | 7 分钟 | 为自己的商品生成 3 版脚本，选 1 版填写 6~8 镜分镜 |
| 收尾 | 2 分钟 | 检查台词长度与画面可生成性，预告图生视频课 |

## Prompt 模板

> 你是电商短视频编导，请为「{商品}」写一条 30 秒带货脚本，目标人群是「{人群}」，按黄金 3 秒钩子、痛点、卖点、背书、CTA 五段输出，并标注每段时长、画面建议和字幕。避免绝对化功效表述。

## 分镜字段

镜号、时长、画面描述/视频提示词、台词/字幕、音效或 BGM、生成方式（图生视频/数字人）。动作保持简单明确，复杂交互拆成多个镜头。

## 课后作业

完成一版可直接用于生成的分镜表，并为每个镜头写出「主体 + 动作 + 运镜 + 光线/风格 + 时长」提示词。
