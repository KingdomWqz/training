# 电商带货短视频AI生成教学大纲（60分钟）

**目标受众**：电商运营、带货主播及希望用AI提效的中小卖家，无需拍摄与剪辑基础  
**教学目标**：在60分钟内了解主流AI视频生成工具的特点与选型方法，掌握带货短视频脚本结构，独立完成"图生视频＋数字人口播＋剪辑合成"的完整短视频生产流程  
**教学形式**：讲解+演示+实操，学员边学边产出  

## 时间分配与内容大纲

### 一、引言：为什么用AI做带货短视频（5分钟）
1. **传统短视频制作的痛点**
   - 成本高：模特、场地、设备、摄影团队缺一不可
   - 周期长：脚本→拍摄→剪辑多轮迭代，跟不上日更节奏
   - 批量难：多SKU店铺无法为每个商品单独拍片
2. **AI生成带来的改变**
   - 文生视频、图生视频让"无实拍"出片成为可能
   - 数字人口播替代真人出镜，一条脚本批量换装、换语言
   - 单条视频制作周期从数天压缩到数十分钟
3. **应用场景速览**
   - 商品动态展示、数字人口播带货、种草短视频、直播间引流切片、多语言出海素材

### 二、主流AI视频生成工具介绍与选型（10分钟）
1. **视频生成大模型**
   - **国际**：Sora（OpenAI）、Veo（Google）、Runway、Luma Dream Machine、Pika
   - **国内**：
     - **可灵AI（快手）**：物理真实感与运动幅度表现好，图生视频一致性强
     - **即梦AI / Seedance（字节）**：生成速度快，中文提示词理解好，与剪映生态打通
     - **Vidu（生数科技）**：多主体参考一致性突出，适合保持商品与角色统一
     - **海螺AI（MiniMax）**：人物表情与动作自然，适合剧情类种草
   - 对比维度：单镜头时长、分辨率、运动合理性、首尾帧控制、积分/价格
2. **数字人与配音工具**
   - **数字人口播**：HeyGen（多语言克隆）、剪映数字人、腾讯智影、闪剪
   - **AI配音**：剪映文字转语音、豆包语音合成、ElevenLabs（出海）
3. **配套环节工具链**
   - 脚本：DeepSeek、ChatGPT等对话式LLM
   - 素材图：即梦AI、Midjourney（衔接《电商封面图制作》课程成果）
   - 剪辑合成：剪映/CapCut（自动字幕、踩点、模板）
4. **选型决策参考**

   | 需求场景 | 推荐方案 |
   |----------|----------|
   | 商品图变动态展示 | 可灵AI、即梦AI 图生视频 |
   | 无真人出镜的口播带货 | 剪映数字人、HeyGen |
   | 多主体一致的剧情种草 | Vidu 参考生视频 |
   | 出海多语言版本 | HeyGen + ElevenLabs |

5. **版权与平台合规提醒**
   - 抖音、视频号等平台对AI生成内容有标识/声明要求，发布时如实勾选
   - 数字人形象与声音须使用官方授权素材，避免侵犯肖像权、声音权
   - 遵守广告法：禁用"最""第一""绝对有效"等违禁表述

### 三、带货短视频脚本创作（15分钟）
1. **爆款脚本五段式公式**
   - `黄金3秒钩子 → 痛点场景共鸣 → 产品卖点展示 → 信任背书 → 行动号召（CTA）`
   - 示例拆解：「还在为杯子里的茶渍发愁吗？*钩子*／泡一次茶洗十分钟*痛点*／这款食品级陶瓷内胆，一冲就净*卖点*／十万用户复购回购*背书*／点击下方小黄车，今天买一送一*CTA*」
2. **用LLM高效生成脚本**
   - Prompt模板：「你是电商短视频编导，请为{商品}写一条30秒带货脚本，目标人群{人群}，包含黄金3秒开头，输出五段式结构并标注每段时长」
   - 迭代技巧：指定口吻（闺蜜安利/专业测评）、加入平台热梗、一次生成3版择优
3. **分镜表：把脚本变成"施工图"**
   - 字段：镜号、画面描述（给AI的提示词素材）、台词/字幕、时长
   - 30秒视频建议6～8个分镜；中文语速约每秒4～5字，据此校准台词长度
4. **现场演示**
   - 用LLM现场生成一条脚本并转成分镜表，作为后续实操任务的公共素材

### 四、实战演练：三类典型带货视频制作（20分钟）
> 说明：AI视频生成耗时较长（每段1～5分钟），课堂采用"讲师课前预生成部分素材＋现场演示＋学员套用素材剪辑"的混合方式，保证进度可控。

1. **任务一：图生视频——商品动态展示（7分钟）**
   - 流程：上传商品图作首帧 → 输入运镜与动作提示词 → 生成5～10秒片段
   - 提示词示例：「缓慢推近镜头，保温杯被拿起倾斜，水流注入杯中激起水花，慢动作特写，商业广告质感」（以《电商封面图》课程产出的场景图为素材更佳）
   - 要点讲评：动作描述要简单明确，复杂交互易崩坏；多用"缓慢""轻微"降低翻车率
   - 学员动手：为自己的商品图生成1段动态展示片段
2. **任务二：数字人口播带货视频（7分钟）**
   - 流程：选择授权形象与音色 → 粘贴任务一的脚本台词 → 生成口播片段 → 检查口型与断句
   - 要点讲评：台词按标点分段粘贴，断句更自然；横竖屏选择要与投放平台匹配（竖屏9:16为主）
   - 学员动手：用讲师提供的脚本生成一段30秒口播视频
3. **任务三：剪映合成完整成片（6分钟）**
   - 流程：导入口播与商品片段 → 自动识别字幕并校对 → 添加BGM与转场 → 调整为9:16 → 导出1080P
   - 要点讲评：商品动态片段插在"痛点/卖点"段落之间；字幕字号确保手机端可读；BGM音量压低不盖人声
   - 学员动手：将前两个任务的素材合成为一条完整带货短视频

### 五、后期处理与发布优化（5分钟）
1. **完整工作流回顾**
   - `LLM写脚本 → 分镜表 → AI生成素材（图生视频/数字人）→ 剪映合成 → 发布`
2. **发布优化要点**
   - 前3秒决定完播率：钩子前置，避免片头Logo式开场
   - 标题埋入搜索关键词，封面与账号主页风格统一
   - 同一脚本换数字人形象/音色/BGM快速产出AB版本测试
3. **发布前检查清单**
   - [ ] 已勾选平台"AI生成内容"声明
   - [ ] 台词无广告法违禁词，商品功效描述真实
   - [ ] 画面比例、字幕、音量在手机端检查无误

### 六、总结与答疑（5分钟）
1. **核心要点回顾**
   - 工具选型：视频模型看真实感与一致性，口播交给数字人，合成靠剪映
   - 内容方法：五段式脚本公式 + 分镜表是AI生产的"总纲"
   - 生产流程：脚本先行、素材并行、剪辑收口
2. **学习资源**
   - 各模型官方文档、教程入口与积分计费说明
   - 拆片练习：收集同行爆款视频，逐镜头反推分镜与提示词
   - 脚本模板与分镜表模板（课后发放，可直接套用）
3. **答疑环节**

## 教学准备清单
- [ ] 讲师提前注册并可登录演示账号：至少1个国内视频模型（可灵/即梦）＋1个数字人工具＋剪映
- [ ] 课前预生成部分视频素材备用，规避现场生成排队等待
- [ ] 准备样例商品图2～3组（可直接沿用《电商封面图制作》课程产出）
- [ ] 准备脚本Prompt模板、分镜表模板（打印或在线文档分享）
- [ ] 测试网络环境与各平台登录状态
- [ ] 测试投影/屏幕共享功能（注意视频播放帧率）

## 预期成果
学员在课程结束后能够：
1. 根据需求（真实感、一致性、口播、出海）选择合适的AI视频工具组合
2. 运用五段式公式撰写带货脚本，并用LLM批量生成与迭代
3. 将脚本转化为分镜表，独立完成图生视频片段制作
4. 使用数字人工具生成口播带货视频
5. 在剪映中完成字幕、BGM、比例调整，产出符合平台规范的完整短视频，并知晓AI内容标注等合规要求
