# 电商封面图AI制作教学大纲（60分钟）

**目标受众**：电商运营、美工新人及希望用AI提效的中小卖家，无需设计基础  
**教学目标**：在60分钟内了解主流图片生成模型的特点与选型方法，掌握封面图提示词写法，独立完成主图、场景图、促销海报三类常用电商封面图  
**教学形式**：讲解+演示+实操，学员边学边出图  

## 时间分配与内容大纲

### 一、引言：为什么用AI做电商封面图（5分钟）
1. **传统封面图制作的痛点**
   - 成本高：模特、场地、摄影、修图的费用门槛
   - 周期长：需求沟通→拍摄→修图多轮迭代，赶不上大促节奏
   - 上新慢：季节款、节日营销素材来不及批量生产
2. **AI生成带来的改变**
   - 分钟级出图，支持快速AB测试不同创意方向
   - 场景不受物理限制："把商品放进任何环境"
   - 边际成本低，适合小批量、多SKU店铺
3. **应用场景速览**
   - 平台主图（白底/场景）、推广Banner、详情页配图、直播预热图、小红书种草图

### 二、主流图片生成模型介绍与选型（10分钟）
1. **国际主流模型**
   - **Midjourney**：光影质感与艺术氛围突出，适合生活方式场景图
   - **GPT Image（ChatGPT）**：自然语言指令理解强，支持对话式改图
   - **Nano Banana（Gemini）**：图像编辑与多图一致性能力优秀，适合保持商品外观统一
   - **Flux / Stable Diffusion**：开源可控，可本地部署、训练专属商品LoRA模型
2. **国内主流模型**
   - **即梦AI（字节 Seedream）**：中文语义理解好，图中渲染中文字准确率高
   - **通义万相（阿里）**：与淘系生态结合紧密，提供电商模板与工作流
   - **腾讯混元、文心一格**等：可作为备选补充
3. **选型决策参考**

   | 需求场景 | 推荐方案 |
   |----------|----------|
   | 海报需要准确中文文案 | 即梦AI、GPT Image |
   | 强调质感氛围的场景图 | Midjourney |
   | 多张图商品外观一致 | Nano Banana、即梦参考图功能 |
   | 数据安全、批量定制 | 本地部署 Flux/SD |

4. **版权与平台合规提醒**
   - 商用前确认所选模型的商用授权条款
   - 关注电商平台对AI生成内容的标识要求，避免虚假宣传风险

### 三、提示词工程基础：写出能出好图的提示词（15分钟）
1. **通用提示词公式**
   - `主体 + 细节特征 + 环境背景 + 构图视角 + 光线氛围 + 风格 + 画质词`
   - 示例拆解：「一只*主体*磨砂质感白色保温杯*细节*，放在原木色桌面*环境*，正面45度俯拍*构图*，清晨柔和侧光*光线*，日系简约风*风格*，商业摄影级画质*画质词*」
2. **电商封面图的关键控制点**
   - **构图**：留白位置要给促销标签、标题文案预留空间
   - **比例**：主图 1:1（建议 800×800px 以上），Banner 16:9 或 3:1，小红书封面 3:4
   - **一致性**：用参考图（垫图）锁定商品颜色、形状、材质，避免"换了个产品"
3. **反向提示词与常见翻车点**
   - 排除项：多余手指、扭曲文字、杂乱背景、水印
   - 典型问题：商品变形、颜色偏差、文字乱码——分别对应的规避写法
4. **现场演示**
   - 同一产品用弱提示词 vs 结构化提示词出图对比，直观感受差距

### 四、实战演练：三类典型封面图实操（20分钟）
1. **任务一：白底产品主图（7分钟）**
   - 提示词示例：「纯白色背景，产品居中45度角摆放，影棚柔光箱布光，底部轻微自然倒影，商业产品摄影，超高清晰度」
   - 进阶技巧：上传实拍图作参考图，保证商品还原度；一次生成4张择优
   - 学员动手：为自己的产品（或讲师提供的样例商品）生成主图
2. **任务二：场景化种草图（7分钟）**
   - 提示词示例：「秋日清晨的木纹餐桌，白色陶瓷马克杯冒着热气，旁边放着牛角包和一本摊开的杂志，暖金色自然光从左侧窗户洒入，浅景深，生活方式摄影」
   - 要点讲评：场景要与目标客群匹配（母婴/数码/家居各有语境）；检查商品是否被场景"吞掉"主体地位
   - 学员动手：为主图添加使用场景，生成1张氛围种草图
3. **任务三：促销海报（含中文文案）（6分钟）**
   - 提示词示例：「618年中大促竖版海报，红色喜庆渐变背景，金色礼品盒堆叠悬浮，画面上方留白区域，底部倒计时元素，电商大促视觉风格」（标题文案后期用工具叠加更稳妥）
   - 要点讲评：文字多的海报推荐"AI出背景+设计工具加字"的组合流程
   - 学员动手：生成1张节日促销背景图

### 五、后期处理与上架优化（5分钟）
1. **常用后期动作**
   - 局部重绘修复瑕疵（手部、文字、边缘毛边）
   - 用Canva、稿定设计等工具叠加Logo、价格标签、促销角标
   - 批量裁剪适配各平台尺寸要求
2. **快速检查清单**
   - 商品外观与实物是否一致（避免售后纠纷）
   - 是否符合平台主图规范（无牛皮癣、无违规水印）
   - AI生成内容是否需要按平台规则标注

### 六、总结与答疑（5分钟）
1. **核心要点回顾**
   - 模型选型：看文字渲染、质感、一致性三大能力对症下药
   - 提示词公式：主体＋环境＋构图＋光线＋风格＋画质词
   - 工作流组合：AI出图 + 设计工具加工 = 可上架成品
2. **学习资源**
   - 各模型官方文档与教程入口
   - 优秀案例库：收集同行爆款封面并反推提示词
   - 提示词模板表（课后发放，可直接套用修改）
3. **答疑环节**

## 教学准备清单
- [ ] 讲师提前注册并可登录各演示模型账号（至少1个国内模型+1个国际模型）
- [ ] 准备样例商品图2～3组（用于参考图/垫图演示）
- [ ] 测试网络环境，确认海外模型可正常访问
- [ ] 准备提示词模板表（打印或在线文档分享）
- [ ] 准备对比案例图：弱提示词 vs 结构化提示词的出图差异
- [ ] 测试投影/屏幕共享功能

## 预期成果
学员在课程结束后能够：
1. 根据自身需求（中文文字、质感、一致性）选择合适的图片生成模型
2. 运用结构化提示词公式独立撰写封面图提示词
3. 独立完成白底主图、场景种草图、促销海报三类电商封面图
4. 使用参考图功能保持商品在多张图中的一致性
5. 了解版权与平台合规要点，将成图按平台规范处理后上架使用
