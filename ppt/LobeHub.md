# LobeHub 教学大纲（60分钟）

**目标受众**：初次接触LobeHub或AI智能体平台的用户  
**教学目标**：在60分钟内掌握LobeHub核心功能，能够独立创建并使用智能体解决实际问题  
**教学形式**：演示+实践，边讲边操作  

## 时间分配与内容大纲

### 一、引言与平台概述（5分钟）
1. **LobeHub是什么**
   - 下一代AI智能体平台，支持长期协作
   - 核心理念：智能体作为工作单元，人类与AI共生进化
2. **平台访问方式**
   - 网页版：[app.lobehub.com](https://app.lobehub.com)
   - 桌面端：macOS/Windows客户端
   - 移动端：iOS/Android应用
3. **界面概览**
   - 左侧边栏：智能体列表、分组、设置
   - 中央区域：对话界面
   - 右侧面板：智能体设置、技能、知识库

### 二、快速开始：创建第一个智能体（15分钟）
1. **使用Agent Builder快速创建（5分钟）**
   - 点击“创建智能体”
   - 用自然语言描述需求（如：“创建一个擅长Python编程的助手”）
   - 自动生成系统提示词、模型配置
2. **手动配置智能体（10分钟）**
   - **系统提示词**：定义角色、专业领域、行为准则
   - **模型选择**：根据任务复杂度选择合适模型
     - 均衡型：GPT-4o、Claude Sonnet
     - 推理型：Claude Opus、GPT-o1
     - 快速型：GPT-4o-mini、Claude Haiku
   - **基础设置**：名称、头像、描述

### 三、核心功能：技能与知识库（15分钟）
1. **技能（插件）系统（8分钟）**
   - **内置技能**：网页搜索、代码执行、图像生成
   - **MCP插件市场**：10,000+工具一键安装
   - **安装演示**：如何添加“网页搜索”技能
   - **使用场景**：让智能体实时获取最新信息
2. **知识库集成（7分钟）**
   - **上传文档**：支持PDF、Word、Markdown等格式
   - **创建专属知识库**：为智能体提供领域知识
   - **关联智能体**：在对话中引用知识库回答
   - **实际案例**：上传产品文档，创建客服助手

### 四、进阶功能：群组协作与记忆（10分钟）
1. **智能体群组（5分钟）**
   - **创建群组**：多个智能体协作完成复杂任务
   - **协作模式**：顺序执行、并行处理、辩论模式
   - **应用场景**：内容创作、代码审查、研究报告
2. **个人记忆（5分钟）**
   - **记忆原理**：智能体从对话中学习用户偏好
   - **白盒记忆**：可查看、编辑、删除记忆内容
   - **跨对话保持**：智能体在不同对话间保持上下文

### 五、社区资源与实际应用场景（10分钟）
1. **社区市场（5分钟）**
   - **智能体市场**：发现并安装社区创建的智能体
   - **技能市场**：扩展智能体能力的插件
   - **二次创作**：基于现有智能体进行个性化修改
2. **典型应用场景（5分钟）**
   - **编程助手**：代码生成、调试、审查
   - **写作伙伴**：文案撰写、文档生成、翻译
   - **研究助理**：文献检索、数据分析、报告生成
   - **效率工具**：日程管理、邮件处理、会议记录

### 六、总结与答疑（5分钟）
1. **核心要点回顾**
   - 智能体创建：描述需求 → 自动配置 → 手动优化
   - 能力扩展：技能 + 知识库 = 专业化智能体
   - 协作模式：单智能体 → 群组协作 → 团队赋能
2. **学习资源**
   - 官方文档：[lobehub.com/docs](https://lobehub.com/zh/docs)
   - 社区论坛：交流经验、获取帮助
   - 示例项目：参考社区优秀智能体配置
3. **答疑环节**

## 预期成果
学员在课程结束后能够：
1. 独立创建并配置个性化智能体
2. 为智能体安装合适的技能插件
3. 上传文档建立专属知识库
4. 使用智能体群组协作完成复杂任务
5. 利用社区资源快速解决实际问题
